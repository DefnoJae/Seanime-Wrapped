# Private soundtrack files

Place legally obtained local audio here before running `npm run build`. Audio is embedded into your private `dist/code.js` at build time and is intentionally ignored by Git.

Supported filenames (the first matching extension is used):

- `inferno.mp3`, `.ogg`, `.wav`, `.m4a`, or `.aac`
- `bling-bang-bang-born.mp3`, `.ogg`, `.wav`, `.m4a`, or `.aac`
- `otonoke.mp3`, `.ogg`, `.wav`, `.m4a`, or `.aac`
- `black-catcher.mp3`, `.ogg`, `.wav`, `.m4a`, or `.aac`

Missing files are safe: the slot is shown as unavailable and Wrapped continues silently or chooses another available track for Random.
